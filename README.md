# 베타아빠 데일리 학습지

초등 1~6학년 수학을 **단원별 하루 10문제**(오늘 단원 7문제 + 지난 단원 복습 3문제)로 만들고, **A4 문제지와 정답·한 줄 풀이**를 프린트하는 무료 학습지 생성기예요.

- 바로 쓰기(설치 없음): https://jpark09014-star.github.io/daily-worksheet/
- 윈도우 PC용 exe: [Releases](https://github.com/jpark09014-star/daily-worksheet/releases/latest)
- 만든 사람: 베타아빠 · 블로그 https://blog.naver.com/geekpapa · 인스타그램 @dad_in_beta

## 할 수 있는 것
- 2022 개정 교육과정 기준 1~6학년, 1·2학기 단원표
- 1차 지원: 수와 연산, 규칙(변화와 관계), 숫자로 계산하는 측정 단원(길이·시간·들이·무게·각도·넓이·부피·원)
- 준비 중: 그림이 필요한 도형·그래프 단원(여러 가지 모양, 평면도형, 원, 막대그래프 등)
- 난이도 3단계: 기본 · 보통 · 도전 (학년 범위를 넘지 않음)
- 계산 문제와 문장제가 섞여 나오고, 정답지에 한 줄 풀이가 붙어요
- 같은 날짜·단원·난이도면 같은 문제가 나와요(학습지 번호로 다시 뽑기). '다른 문제로'를 누르면 새 문제가 나와요

## 사용 방법
1. 학년과 학기를 고르고, 학교에서 오늘 배운 단원을 눌러요
2. 난이도와 날짜를 확인해요
3. `프린트하기` → 용지 A4, 배율 100%(또는 기본). 1장은 문제지, 2장은 정답과 풀이예요

## 알아 두세요
- 3~6학년은 학교마다 교과서 출판사가 달라 단원 이름·순서가 조금 다를 수 있어요. 단원 이름으로 골라 주세요.
- 문제는 모두 프로그램이 직접 만들어요. 다른 사이트나 교과서의 문제를 옮기지 않았어요. 모든 문제는 정답을 다른 방법으로 다시 계산해 확인해요(단원·난이도별 대량 생성 검사 통과).

## exe 버전 안내
- 설치 없이 더블클릭으로 열려요. 인터넷 연결이 없어도 되고 개인정보를 모으거나 보내지 않아요. 마지막으로 고른 학년·단원만 이 기기에 저장해요.
- 서명 인증서가 없는 개인 제작 프로그램이라 처음 실행할 때 'Windows의 PC 보호' 창이 뜰 수 있어요. `추가 정보` → `실행`. 걱정되면 웹버전을 쓰세요.
- 받은 파일 확인: PowerShell에서 `Get-FileHash .\베타아빠데일리학습지.exe` 값을 Releases의 SHA256과 비교하세요.

## 이용 안내
- 가정·학교·공부방에서 무료로 쓰세요. 만든 학습지는 자유롭게 출력해 나눠 주셔도 돼요.
- 프로그램 파일을 다른 곳에 올리거나 판매하지 말아 주세요. 공유할 때는 이 페이지나 블로그 링크로 알려 주세요.
- 글꼴: 주아체(Jua, SIL Open Font License 1.1, `Jua-OFL.txt`)를 필요한 글자만 줄여서 넣었어요.

## 직접 빌드하기
- `src/gen.js`: 단원표와 문제 생성기 (`node test.js`로 대량 검산)
- `build-web.ps1`: `src/app.html` + `gen.js` + 주아체 일부 글자 → `docs/index.html` (Python fontTools 필요)
- `build-exe.ps1`: 윈도우 내장 .NET Framework 컴파일러(csc)로 `dist/베타아빠데일리학습지.exe`
